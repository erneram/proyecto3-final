# Compiscript

Compilador de Compiscript escrito en TypeScript. Analiza el programa fuente, valida su semántica, genera código de tres direcciones y produce ensamblador MIPS32 que se ejecuta en MARS 4.5.

## Requisitos

- Node.js 22.12 o superior
- Java 17 o superior (solo para ejecutar el ensamblador en MARS)

## Instalación

```bash
npm install
```
